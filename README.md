# PLP Python Week 7 Assignment

## File Descriptions
- **my_notes.py**: Python script that writes, appends, reads, and counts text lines in a note file.
- **my_notes.txt**: Text file generated by `my_notes.py` containing four stored notes.
- **report_builder.py**: Python script that reads CSV data, processes scores, handles missing files safely, and writes a summary report.
- **hubs.csv**: Source CSV dataset containing learner names, hubs, and scores.
- **report.txt**: Generated summary report detailing total learners, pass/fail counts, and average score.
